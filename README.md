## My work

I work with SharePoint, Azure and Entra ID, and I have a lot of fun combining them together.  
This is how I created [this azd template](https://github.com/Azure-Samples/azd-functions-sharepoint-webhooks), that modernizes the deployment of an Azure function app to create webhooks on SharePoint.  
I did other similar projects, [such as this one](https://github.com/Yvand/azd-function-spfx-custom-api), that automates [consuming an enterprise API](https://learn.microsoft.com/en-us/sharepoint/dev/spfx/use-aadhttpclient-enterpriseapi) in a custom SPFx solution.  
But wait, SharePoint Server is still there! So, to save some precious coffee time, I created this [Terraform module](https://registry.terraform.io/modules/Yvand/sharepoint/azurerm/latest) and [Bicep template](https://learn.microsoft.com/en-us/samples/azure/azure-quickstart-templates/sharepoint-adfs/) to easily deploy it on Azure. If you work with SharePoint Server, you should try them. I use them all the time and continually improve them for my own needs.  
And how to not mention [LDAPCP](https://github.com/Yvand/LDAPCP) (the most popular claims provider for SharePoint) and [EntraCP](https://github.com/Yvand/EntraCP) (the second most popular claims provider for SharePoint) (of course totally based on my own, subjective estimates).  
But trust me, sometimes, I definitely do my core job: Investigating and fixing issues in SharePoint (I care a lot about keeping my boss happy).
